# Data Cleaning & Reporting Automation

## Project Description
This project automates data cleaning and report generation using Python.

## Features
- Remove duplicate records
- Fill missing values
- Generate cleaned CSV
- Create salary chart
- Generate summary report

## Technologies Used
- Python
- Pandas
- Matplotlib

## Files
- main.py
- sample_data.csv
- requirements.txt
- output/
- reports/
- images/

## How to Run

```bash
pip install -r requirements.txt
python main.py
```
